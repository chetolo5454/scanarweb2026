# WebScan — تطبيق ويب لمسح المستندات محلياً

WebScan هو تطبيق ويب محلي متكامل يحول هاتفك إلى ماسح ضوئي لاسلكي للمستندات. يعمل التطبيق محلياً على جهاز الكمبيوتر الخاص بك، ويبث صور الكاميرا بشكل آمن من هاتفك عبر WebRTC/Socket.io، ويوفر ميزات تصحيح المنظور، وتطبيق الفلاتر، وتصدير الملفات بتنسيق PDF دون الحاجة إلى تثبيت أي تطبيق على الهاتف المحمول.

## المتطلبات الأساسية

- Node.js إصدار 18 فما فوق (Node.js v18+)

## التثبيت

```bash
git clone <repo-url>
cd webscan
npm install
```

## التشغيل (باستخدام HTTP)

```bash
npm start
```

استخدم HTTP عند تشغيل التطبيق على شبكتك المحلية وعند الاختبار باستخدام الأجهزة/المتصفحات التي لا تفرض سياقات آمنة صارمة للوصول إلى الكاميرا (مثل بعض إصدارات متصفح Chrome على نظام Android عند الاختبار محلياً).

## التشغيل (باستخدام HTTPS)

```bash
npm run start:https
```

استخدم HTTPS عندما يطلبه المتصفح للوصول إلى `getUserMedia` (واجهة برمجة تطبيقات الكاميرا). هذا مطلوب بشكل صارم لمتصفح Safari على نظام iOS والعديد من متصفحات Android الحديثة.
نظراً لأن التطبيق يقوم بإنشاء شهادة موقعة ذاتياً (self-signed certificate) أثناء التشغيل:
1. افتح الرابط على هاتفك.
2. سيحذرك المتصفح من أن الاتصال غير خاص.
3. على متصفح Safari في iOS: اضغط على "إظهار التفاصيل" (Show Details) -> "زيارة هذا الموقع" (visit this website) -> "زيارة الموقع" (Visit Website).
4. على متصفح Chrome في Android: اضغط على "متقدم" (Advanced) -> "متابعة إلى [رقم IP] (غير آمن)" (Proceed to [IP] (unsafe)).

## دليل الاستخدام

1. قم بتشغيل التطبيق (باستخدام HTTP أو HTTPS) على جهاز الكمبيوتر الخاص بك.
2. افتح متصفح الكمبيوتر وانتقل إلى `http://localhost:3000` (أو عنوان IP الموضح في موجه الأوامر).
3. قم بتوصيل هاتفك بنفس شبكة Wi-Fi وامسح رمز الاستجابة السريعة (QR code) المعروض على شاشة الكمبيوتر، أو اكتب الرابط يدوياً في متصفح الهاتف.
4. على هاتفك، اضغط على "انقر لتفعيل الكاميرا" (Tap to Activate Camera) وامنح صلاحيات الوصول للكاميرا.
5. وجّه هاتفك نحو مستند واضغط على زر الالتقاط. سيتم بث الصورة إلى جهاز الكمبيوتر.
6. التقط صوراً بالقدر الذي تحتاجه، ثم اضغط على "تم" (Done) على الهاتف أو "تم المسح" (Done Scanning) على الكمبيوتر.
7. على الكمبيوتر، حدد كل صفحة لاستخدام ميزة قص المنظور (Perspective Crop) لضبط حدود المستند.
8. قم بتطبيق الفلاتر (سحري Magic، أبيض وأسود B&W، طباعة Print، صورة Photo) لتحسين المستند.
9. انقر على "تنزيل الكل كملف PDF" (Download All as PDF) لإنشاء مستندك النهائي وحفظه.

## استكشاف الأخطاء وإصلاحها

- **تم رفض إذن الكاميرا:** تأكد من أنك منحت صلاحيات الكاميرا. على نظام iOS، تحقق من الإعدادات > Safari > الكاميرا. على نظام Android، تحقق من إعدادات Chrome > إعدادات المواقع > الكاميرا. إذا كنت تستخدم iOS، تأكد من تشغيل التطبيق باستخدام HTTPS.
- **الهاتف لا يستطيع الوصول إلى الخادم:** تأكد من أن هاتفك وجهاز الكمبيوتر متصلان بنفس شبكة Wi-Fi. تحقق مما إذا كان جدار الحماية (Firewall) لجهاز الكمبيوتر يمنع عملية Node.js (المنفذ 3000). قد تحتاج إلى تعطيل جدار الحماية مؤقتاً أو إضافة قاعدة للسماح بالاتصالات الواردة على المنفذ 3000.
- **رمز الاستجابة السريعة لا يظهر:** تأكد من أن جهاز الكمبيوتر الخاص بك يحتوي على عنوان IP محلي صالح ومتصل بشبكة.
